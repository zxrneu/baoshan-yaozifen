# AI 对局观看与动作展示

顶栏点击「观看 AI 对局」，当前对局的四个座位均由 AI 接着行动。观战显示四家手牌，AI 决策仍只接收本阶段合法观察。退出观战后对局暂停，恢复原先座位配置及普通牌桌的可见范围。

「暂停／继续」随时控制播放；「下一步」或空格会暂停自动播放，只推进当前展示步骤。没有待展示步骤时才让 AI 做一次决策。查看头像的决策原因、点击已可见的牌放大时，自动暂停；返回牌桌后点击「继续」。决策理由来自实际记录，尚未生成理由时会明确说明。

动作文字靠近行动玩家，使用数字、花色、翻牌及移动效果，不用大矩形弹窗遮挡牌桌。自动模式每一步保留阅读时间；切换观看速度影响停留时间，暂停不会丢失当前或后续步骤。展开底部对局记录可逐项查看本次已观察动作。

| 动作 | 可观察内容 |
| --- | --- |
| 发牌／四家不叫后的重发 | 四家手牌和桌面底牌数量，下一家叫分座位 |
| 每家叫分／不叫 | 行动座位与叫分数值，叫分数字浮起 |
| 确定庄家 | 庄家座位、最终叫分和下一步定主 |
| 定主 | 庄家旁亮出主牌花色 |
| 翻底 | 原底牌逐张翻开，具体牌面与总分 |
| 起底入手 | 原底牌移向庄家，手牌 12 → 16，摸入的牌带「底」标记 |
| 扣底 | 选中底牌与去向，16 → 12，牌背回到桌面 |
| 100 分搭档明牌 | 成功扣底后才展示搭档剩余手牌 |
| 领出／跟牌／主牌杀入／垫牌 | 每张牌从行动座位进入桌面，本墩第几张牌 |
| 收墩 | 第四张牌先停留，再将四张牌收向赢家；0 分墩也展示 |
| 分数入账 | 赢家所属队加分，庄闲两方分数变化 |
| 本副／整场结算 | 最后显示胜方和最终比分，再提供下一副／新一场入口 |

普通玩家模式中，别家起底和扣底只展示牌背及数量；个人原底牌、规则公开牌和明确授权的透视牌才显示牌面。观战展示层不参与 AI 输入投影。

撤销、从起点回放及恢复快照会清理旧展示；恢复一步会重新展示相应动作；新副和重开重新展示发牌。对局规则、提交历史与动作展示分别管理，展示中间画面不写回引擎状态。
