# 玩家指南

> 文档类型：当前使用说明；复核日期：2026-10-15。启动见[项目首页](../../README.md)，规则见[玩法规则](rules.md)，返回[文档索引](../README.md)。

手机请横屏游玩：竖屏显示“请横屏”提示，切回横屏保留当前选择和对局；手机横屏采用紧凑牌桌，手牌与右侧主要操作位于首屏，次要工具在侧栏滚动查看。

手机 Debug 与观战将四家手牌分成独立区域，按家名辨认座位，左右滑动每家的手牌查看全部牌张；拖动不会选牌。下一步、退出观战和当前行动优先显示在右侧。

## 开始对局

默认坐南家（下方），东家在右、西家在左、北家在上。按阶段完成叫分、定主、扣底与出牌；界面提示当前行动者、合法候选及庄闲成局线。点击牌桌上的各家引擎名称可改变人工与 AI 分配。

打开页面后先暂停。点击各家引擎名称单独设置玩家与打法，再按顶栏「开始」推进；「暂停」随时停止自动推进，Debug 可用「下一步」单步检查。设置中不再提供两队或统一打法覆盖入口。

## 单副练习

顶栏点击「单副练习」开始一副独立的新牌。原标准对局暂停并保留；练习复制当前四座打法配置，胜负正常结算或提前锁定后即结束。练习结算提供「复盘本副」与「返回标准对局」，不自动发第二副。

随时点击「退出练习」可回到原标准对局，牌局、比分与四座配置保持原样，返回后按顶栏「开始」继续。此返回依赖当前页面保留的会话，刷新后的对局可从已保存历史恢复。练习的座位配置、调试偏好和待保存队列与原局隔离；练习使用独立历史身份与 `targetWins=1`。

## 新手短教学

顶栏点击「新手教学」，用固定公开题目完成两段练习：选出 A / 10 / 5 分牌；学习有同门必须跟、缺门可以用主牌杀或垫牌。选择后须点击「确认分牌 / 确认出牌」，不会自动提交；漏选或误选会给出说明并保留选择，可纠正后重试。

每段都可点击「跳过本段」，也可随时点击「退出教学」或按 Escape 返回。跳过的内容不会标为练习完成。教学暂停当前标准局或单副练习，保留牌局、历史和配置；返回后自行继续。题目仅使用示例牌张与公开领牌，不调用模型、不写入对局历史；重新打开会从第一题开始。定主、扣底与目标线教学仍待扩展。

## AI 对局观看

顶栏点击「AI 接管本局（公开手牌）」进入观战，点击「开始」观看四座 AI 连打，随时用同一按钮暂停／继续，按「下一步」或空格逐项观察。起底先翻开具体底牌再展示入手，动作说明与推进集中在右侧；点头像查看真实决策原因，点可见牌放大，查看时自动暂停。全部动作及可见范围见[观战与动作展示说明](../features/ai-spectator-actions.md)。

观战继续当前这一局，退出时保留已推进的进度并暂停；进入和退出会清除尚未提交的选牌。Debug 重开请点击「重开此副」，裸字母 R 不再重开。

## 多配置引擎与四座选择（P2）

复制 `engine-profiles.example.json` 为 `engine-profiles.json`，在 `.env` 设置 `ENGINE_PROFILES_PATH=engine-profiles.json` 并填写各组模型端点/密钥。文件支持多 LLM、多 System One 与多组 Bridge/Algorithm 参数，校验后生成不可变版本。留空时迁移现有单配置默认值。

点击牌桌上的各家引擎名称可逐座选择 Human 或任意配置；“开发者选项”可重载文件、编辑参数并原子保存新版本。当前副牌版本冻结，显式换配置取消旧请求，下一副采用目录新版本。历史保存实际配置和回退链；本地模式支持 Bridge/Algorithm，模型配置由 Node HTTP 服务解析环境引用。模板、HTTP 契约、预算与恢复边界见 [P2 实现说明](../features/engine-profiles.md)。

## 对局历史与复盘（P0 / P1）

牌桌顶部显示“保存中 / 已保存 / 未保存”，点击“对局历史”可分页查询，按状态、来源、日期、引擎与叫分筛选，查看副牌详情、导出带摘要与版本校验的完整动作记录，并暂停恢复未结束副牌。刷新浏览器或重启服务后记录仍在 SQLite 中。

本副或本场结算时点击「复盘本副」，直接打开本副已保存的真实叫分、定主、扣底与出牌时间线；「返回结算」回到原结果。关闭结算回看牌桌后也保留复盘入口。保存中、保存失败或历史不可用时，入口禁用并说明原因；加载失败可重试。

`pnpm dev` 与 `pnpm run server` 共用 `/api/history/`，`GAME_DB_PATH` 默认 `data/history.db`。保存失败会暂停自动推进，并保留浏览器待保存队列；用“重试保存”重发同一身份，成功后需自行继续。损坏的待保存日志保留原文，可导出排查，不清空数据库。

历史记录包含完整私有牌局与 seed，只用于存储、恢复和规则校验；普通 AI 始终接收阶段观察。P2 存档恢复后继续使用当时四座配置的冻结版本；先校验服务环境与参数，失败不覆盖活动局。旧默认存档保留兼容行为。纯离线 Tauri 原生历史与历史文件导入尚未实现。协议、事务和验收证据见 [P0 实现说明](../features/history-storage.md)。

详情中点击“开始复盘”可步进、轮次/阶段跳转、播放暂停，并切换座位查看当时观察与决策诊断。点击“新建分支”可换动作或用当前默认引擎继续模拟本副；分支写入同一 SQLite 库，原路径和结算保留，并可比较多个后续。切换节点或配置会取消旧请求；全牌复盘只影响显示，不扩散到 AI 输入。使用范围与验证见 [P1 实现说明](../features/history-replay.md)。

## 模拟对战

“对局历史 → 模拟对战”支持选择四座配置、发牌集、预算与并发，执行同种子换边批跑；可选择全生命周期或固定前三阶段，仅比较出牌。“历史复盘 → 配置四座独立续打”从当前节点建立独立模拟分支，保留原路径和活动牌局。

结果与进度保存在同一 SQLite 库，支持取消、服务重启后续跑，并从报告打开每组两局复盘。报告按实际赢副统计组级区间，展示合同、成约、耗时和失败/回退归因；小样本不宣称牌力排名。冻结版本、累计预算、源码/服务兼容边界与测试证据见 [P3 实现说明](../features/simulations.md)。

## 声音与牌面

顶部「音效」与「报牌」可分别开关，设置保存在本机。首次点击或按键后启用声音；中文报牌播报公开的叫分、定主、出牌与收分，不读出底牌或扣底牌面。语音优先使用系统中文语音；浏览器不支持时会禁用报牌入口，操作音效仍可独立使用。

不能出的手牌用不透明的灰色牌面标识，并显示跟牌或扣底限制；等待其他玩家时保留正常牌面。100 分明牌局中，公开手牌紧贴对应玩家的头像，使用和自己手牌相同的扑克牌面叠放，空间不足时连续换行。

右上角「换皮肤」可即时切换经典棋牌（默认青绿绒面与红木围边）、森林绿和午夜蓝。选择会保存在本机，刷新后恢复；换肤保留当前对局与选牌。
